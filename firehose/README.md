# Midterms firehose

`scrape.py` pulls every feed in `sources.json` (generated by `build_sources.py`) and writes
`docs/data.json`; `docs/index.html` renders it and re-fetches every minute.
The `firehose` GitHub Actions workflow runs every 5 minutes and commits the data.
Serve with GitHub Pages: Settings → Pages → Source: **GitHub Actions** (pages.yml deploys `docs/` after each data commit). Election night: every 5 min until 7 PM ET, real-time (~60s) loops 6:40 PM–1 AM ET, paused 1–6 AM, real-time loops 6 AM–11 PM ET Nov 4, then no more schedules. Note: the crons name Nov 3–5 and would recur next year — delete or edit the workflow after the election.
