# Midterms firehose

`scrape.py` pulls every feed in `sources.json` (generated by `build_sources.py`) and writes
`docs/data.json`; `docs/index.html` renders it and re-fetches every minute.
The `firehose` GitHub Actions workflow runs every 5 minutes and commits the data.
Serve `docs/` with GitHub Pages (Settings → Pages → Deploy from branch → main /docs).
